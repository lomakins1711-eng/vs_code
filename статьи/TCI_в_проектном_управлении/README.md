# Что такое TCI в проектном управлении

В проектном управлении аббревиатура `TCI` неоднозначна. В классическом контроле стоимости проекта чаще встречается `TCPI` - `To-Complete Performance Index`, индекс эффективности, которую нужно обеспечить на оставшейся части проекта, чтобы уложиться в целевой бюджет.

Также `TCI` может означать `Theme-centered interaction` - метод работы с группами и командами. Это ближе к фасилитации, обучению и групповой динамике, чем к финансовому контролю проекта.

## Короткая формула TCPI

Если нужен именно индекс `TCPI`, то базовая идея такая:

```text
TCPI = (BAC - EV) / (BAC - AC)
```

Где:

- `BAC` - бюджет по завершении проекта;
- `EV` - освоенный объем;
- `AC` - фактические затраты.

Смысл: показатель показывает, с какой эффективностью по затратам нужно выполнить оставшуюся работу, чтобы достичь целевого бюджета.
