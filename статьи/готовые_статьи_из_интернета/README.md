## Примечание

`TCI` не является такой же однозначной аббревиатурой, как `TCO`. В этой подборке файлы `09-11` помогают читать TCI как `Total Capital Investment`: капитальные затраты, основной капитал и оборотный капитал. В конкретном проекте расшифровку `TCI` лучше фиксировать явно.
