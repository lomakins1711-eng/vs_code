# Пример реализации расчета TCO на 1С

Ниже пример универсального расчета TCO, который можно положить в общий модуль, например `УправлениеTCO`.

Пример не зависит от конкретной конфигурации. Он принимает таблицу затрат и возвращает:

- простую сумму TCO;
- дисконтированную сумму;
- итоги по статьям затрат.

## Структура входных данных

Таблица значений `Затраты`:

| Колонка | Тип | Описание |
| --- | --- | --- |
| `Период` | Дата | Дата или период возникновения затрат |
| `Статья` | Строка | Наименование статьи затрат |
| `ВидЗатрат` | Строка | Например `Приобретение`, `Внедрение`, `Эксплуатация`, `Риск`, `Вывод` |
| `Сумма` | Число | Сумма затрат |
| `Вероятность` | Число | От 0 до 1. Для обычных затрат можно ставить 1 |

Структура `ПараметрыРасчета`:

| Поле | Описание |
| --- | --- |
| `ДатаНачала` | Дата начала расчета |
| `СтавкаДисконтирования` | Годовая ставка, например `0.15` для 15% |
| `УчитыватьДисконтирование` | Истина/Ложь |
| `Затраты` | Таблица значений |

## Пример вызова

```bsl
ПараметрыРасчета = Новый Структура;
ПараметрыРасчета.Вставить("ДатаНачала", Дата(2026, 1, 1));
ПараметрыРасчета.Вставить("СтавкаДисконтирования", 0.15);
ПараметрыРасчета.Вставить("УчитыватьДисконтирование", Истина);
ПараметрыРасчета.Вставить("Затраты", ПодготовитьПримерЗатратTCO());

Результат = УправлениеTCO.РассчитатьTCO(ПараметрыРасчета);

Сообщить("TCO: " + Формат(Результат.Итого, "ЧДЦ=2"));
Сообщить("Дисконтированный TCO: " + Формат(Результат.ИтогоДисконтированное, "ЧДЦ=2"));
```

## Что считать в реальном проекте

Для внедрения 1С в TCO обычно стоит включить:

- лицензии платформы и прикладных решений;
- серверы, СУБД, облако, терминальный доступ;
- обследование, проектирование, разработку и настройки;
- интеграции с банками, ЭДО, сайтами, WMS, CRM, BI;
- миграцию данных;
- обучение и сопровождение пользователей;
- обновления платформы, конфигурации и расширений;
- регламентное обслуживание, резервное копирование, мониторинг;
- стоимость простоев и критичных инцидентов;
- развитие системы после запуска;
- вывод из эксплуатации старой системы.
